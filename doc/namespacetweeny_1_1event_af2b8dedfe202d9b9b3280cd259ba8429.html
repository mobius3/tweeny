detail::event::keyframeLeave_t keyframeLeave {}
inlineconstexpr

Event triggered when leaving a keyframe segment.

Fires when the tween transitions out of a keyframe section during playback. The callback receives both the tween reference and a keyframeLeave struct containing the keyframe index being exited.

Common use cases:

  • Cleaning up phase-specific resources
  • Stopping phase-specific effects
  • Logging animation progression
  • Implementing phase exit handlers
  • Coordinating complex multi-segment animations
Note
Keyframe indices are 0-based. Leaving keyframe 0 means transitioning from the first to the second segment.
auto tween = tweeny::from(0)
.to(50).during(30U)
.to(100).during(30U)
.build();
tween.on(tweeny::event::keyframeLeave, [](auto& t, tweeny::event::keyframeLeave evt) {
printf("Leaving keyframe %zu\n", evt.key_frame);
return tweeny::event::response::ok;
});
tween.step(31); // Triggers: "Leaving keyframe 0"
