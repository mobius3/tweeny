Detailed Description

template<typename FirstValue, typename... RemainingValues>
class tweeny::tweeny_builder< false, FirstValue, RemainingValues... >

Builder specialization for the stage before the first to() call.

Holds the initial key-frame values and allows adding the next key-frame via to(). Calling to() transitions the builder to the WasToCalled=true specialization; build() can be used to create a tween with the currently collected key-frames.

Template Parameters
FirstValueType of the first tweened component.
RemainingValuesTypes of the remaining tweened components.
