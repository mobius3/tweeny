tweeny_builder< true, FirstValue, RemainingValues... > to ( const FirstValue & firstComponent,

inline

Adds a target keyframe to the tween.

Specifies the destination value(s) for the animation. After calling this, you can configure easing and duration with via() and during().

Parameters
firstComponentTarget value for the first component
remainingComponentsTarget values for remaining components (if multi-value tween)
Returns
Builder in a configurable state (can call via(), during(), to(), or build())
auto t = tweeny::from(0).to(100).during(60U).build();
