template<typename... EasingFunctionTypes>
tweeny_builder & via ( EasingFunctionTypes... easing_functions)
inline

Specifies per-component easing functions for the last keyframe segment.

Each tween component gets its own easing function. The number of easing functions must match the number of tween components (compile-time checked).

Parameters
easing_functionsOne easing function per tween component
Returns
Reference to this builder for method chaining
// Two components with different easings
auto t = tweeny::from(0, 0.0f)
.to(100, 50.0f)
.via(easing::linear, easing::bounceOut)
.during(60U)
.build();
