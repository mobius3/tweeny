template<typename FirstValue, typename... RemainingValues>
tweeny_builder & during ( uint32_t frame_count)
inline

Specifies a uniform frame duration for all components.

All tween components will animate over the same number of frames. This is the most common usage.

Parameters
frame_countDuration in frames for the animation segment
Returns
Reference to this builder for method chaining
// Animate from 0 to 100 over 60 frames
auto t = tweeny::from(0, 0).to(100, 100).during(60U).build();
