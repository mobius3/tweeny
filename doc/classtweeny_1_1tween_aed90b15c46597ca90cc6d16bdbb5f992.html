template<typename FirstValueType, typename... RemainingValueTypes>
auto peek ( ) const -> tween_value_t
nodiscard

Returns the current interpolated value without changing state.

Non-mutating query of the tween's current value. Does not trigger events or modify the tween's position.

Returns
Current interpolated value
auto t = tweeny::from(0).to(100).during(100U).build();
t.step(25);
auto val = t.peek(); // Returns 25, doesn't change state
