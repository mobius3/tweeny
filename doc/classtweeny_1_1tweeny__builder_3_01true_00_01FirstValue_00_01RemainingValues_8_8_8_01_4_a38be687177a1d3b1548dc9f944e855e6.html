template<typename FirstValue, typename... RemainingValues>
tweeny_builder to ( const FirstValue & firstValue,
const RemainingValues &... remainingValues ) &
inline

Adds another keyframe to create multipoint animations.

Call to() multiple times to create complex animations with multiple segments, each with its own easing and duration.

Parameters
firstValueTarget value for the first component
remainingValuesTarget values for remaining components
Returns
Reference to this builder for method chaining
// Three-point animation: 0 → 50 → 100
auto t = tweeny::from(0)
.to(50).via(easing::quadraticOut).during(30U)
.to(100).via(easing::bounceOut).during(30U)
.build();
