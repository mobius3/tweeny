Detailed Description

template<bool WasToCalled, typename FirstValue, typename... RemainingValues>
class tweeny::tweeny_builder< WasToCalled, FirstValue, RemainingValues >

Primary template for the tween builder type.

Models a fluent builder used to construct tween instances for one or more parts. The boolean template parameter encodes the builder state: when false, no to() call has been made yet; when true, easing functions and durations can be configured.

Template Parameters
WasToCalledCompile-time flag indicating whether at least one to() call has been made.
FirstValueType of the first tweened component.
RemainingValuesTypes of the remaining tweened components.
