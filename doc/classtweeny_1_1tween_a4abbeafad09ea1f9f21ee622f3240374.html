template<typename Callback>
auto on ( detail::event::keyframeEnter_t ,
Callback && cb ) -> void

Registers a callback for entering a keyframe.

The callback is invoked when the tween transitions into a new keyframe section. Receives the tween reference and event data containing the keyframe index.

Parameters
cbCallback with signature: event::response(tween&, event::keyframeEnter)
auto t = tweeny::from(0).to(50).during(30U).to(100).during(30U).build();
t.on(event::keyframeEnter, [](auto& tween, auto evt) {
printf("Entered keyframe %zu\n", evt.key_frame);
return event::response::ok;
});
t.step(31); // Triggers: "Entered keyframe 1"
